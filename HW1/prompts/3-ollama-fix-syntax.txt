FIX 1. The draft writes "class FINANCING {". The word "class" belongs to Mermaid class diagrams, not ER diagrams, and it is a parse error here. An entity block starts with just the entity name:

    FINANCING {

FIX 2. The draft writes attributes as "PK loan_id int". The order is wrong. In Mermaid, the type comes first, then the name, then an optional PK or FK marker at the end:

    int loan_id PK
    decimal loan_amount
    int staff_id FK

FIX 3. The draft has no relationship lines at all, so it is not an ER diagram, just a list of tables. After all the entity blocks you must add relationship lines in this form:

    PATIENT ||--o{ APPOINTMENT : books
    MEDICAL_PROFESSIONAL ||--o{ APPOINTMENT : serves

Every entity you define must appear in at least one relationship line. Use || for exactly one, o{ for zero or more, |{ for one or more. The label after the colon must be a single word, or in double quotes if it has spaces.
